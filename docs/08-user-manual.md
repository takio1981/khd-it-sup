# 8. User Manual (คู่มือผู้ใช้งาน)

สำหรับผู้ใช้งานทั่วไป (Role: **User**) — เจ้าหน้าที่ในหน่วยงานที่ต้องการแจ้งซ่อมครุภัณฑ์คอมพิวเตอร์ หรือยืม-คืนครุภัณฑ์

URL ของระบบต้องมี path `/khd-it-sup/` ต่อท้ายเสมอ (เช่น `http://it-support.nma-pho.local/khd-it-sup/`)

## 8.1 หน้าแรก (Landing Page) และการเข้าสู่ระบบ

1. เปิดเบราว์เซอร์ไปที่ URL ของระบบ — จะเห็นหน้าแนะนำระบบ (ไม่ต้อง login) พร้อมปุ่ม **"เข้าสู่ระบบ"**
2. กรอกชื่อผู้ใช้และรหัสผ่านที่ได้รับจากผู้ดูแลระบบ
3. หากเป็นการเข้าสู่ระบบครั้งแรก ระบบจะบังคับให้เปลี่ยนรหัสผ่านทันที
4. **ลืมรหัสผ่าน?** กดลิงก์ "ลืมรหัสผ่าน?" ใต้ช่องกรอกรหัสผ่าน → กรอกชื่อผู้ใช้หรืออีเมล → ระบบจะส่งลิงก์ตั้งรหัสผ่านใหม่
   ไปยังอีเมลที่ลงทะเบียนไว้ (ลิงก์หมดอายุภายใน 30 นาที ใช้ได้ครั้งเดียว) — ไม่ต้องรอผู้ดูแลระบบรีเซ็ตให้อีกต่อไป

## 8.2 การนำทางในระบบ: ซ่อน/แสดงเมนู และค้นหาข้อมูลข้ามระบบ

ที่มุมซ้ายบนของระบบจะมีปุ่มกลุ่มเล็ก ๆ 2 ปุ่มอยู่ด้วยกันเสมอ (อยู่ติดกับกล่องชื่อระบบ "KHD-IT-SUP" เมื่อแถบเมนูซ้ายเปิดอยู่
หรือย้ายไปอยู่แถบด้านบนแทนเมื่อแถบเมนูถูกซ่อน — ไม่หายไปไหน):

- **ปุ่มซ่อน/แสดงเมนู** (ไอคอน ☰) — กดเพื่อซ่อนแถบเมนูซ้ายชั่วคราว ขยายพื้นที่ทำงานให้กว้างขึ้น โดยเฉพาะเมื่อดูตารางข้อมูลที่มี
  หลายคอลัมน์ กดซ้ำเพื่อแสดงเมนูกลับคืน
- **ปุ่มค้นหา** (ไอคอนแว่นขยาย 🔍) — เปิดหน้าต่างค้นหาข้ามระบบ พิมพ์คำค้นหาแล้วระบบจะค้นให้ทันทีจากหลายแหล่งข้อมูลพร้อมกัน:
  - **งานแจ้งซ่อม** — ค้นได้จากเลขที่ใบแจ้งซ่อม, รายละเอียดอาการเสีย, หรือ**ชื่อผู้แจ้ง**
  - **ครุภัณฑ์** — ค้นได้จากเลขครุภัณฑ์, ยี่ห้อ, รุ่น
  - **ผู้ใช้งาน** — ค้นได้จากชื่อ-นามสกุล, username, อีเมล
  - **รายการยืม-คืนอุปกรณ์** — ค้นได้จากครุภัณฑ์หรือชื่อผู้ยืม

  กดที่ผลลัพธ์รายการใดก็ได้เพื่อไปยังหน้าที่เกี่ยวข้องโดยตรงทันที — ผลการค้นหาจะแสดงเฉพาะประเภทข้อมูลที่ท่านมีสิทธิ์เข้าถึง
  เท่านั้น (เช่น ถ้าไม่มีสิทธิ์ดูรายชื่อผู้ใช้งาน ผลการค้นหาก็จะไม่แสดงหมวดผู้ใช้งานให้เห็น)

แถบด้านบนสุดของหน้าจอ (โลโก้/ชื่อองค์กร/กระดิ่งแจ้งเตือน/รูปโปรไฟล์) จะอยู่ตรึงด้านบนเสมอแม้เลื่อนหน้าจอลงไปดูข้อมูลด้านล่าง
ไม่ต้องเลื่อนกลับขึ้นไปบนสุดเพื่อกดใช้งานปุ่มต่าง ๆ เหล่านี้

## 8.3 การแจ้งซ่อม/ยืม-คืนผ่านการสแกน QR Code (แนะนำ — เร็วที่สุด)

1. มองหาสติกเกอร์ QR Code ที่ติดอยู่บนครุภัณฑ์ (คอมพิวเตอร์ เครื่องพิมพ์ ฯลฯ)
2. ใช้กล้องมือถือสแกน QR Code — ระบบจะเปิดหน้าเว็บแสดงข้อมูลครุภัณฑ์นั้นทันที **โดยไม่ต้อง login ก่อนและไม่ต้องพิมพ์ข้อมูล
   ครุภัณฑ์เอง**
3. หน้าจอจะแสดง: เลขครุภัณฑ์, ยี่ห้อ/รุ่น, หน่วยงาน, สถานะปัจจุบัน, **รูปภาพครุภัณฑ์ทั้งหมดที่เคยบันทึกไว้ในระบบ**
   (แตะรูปเพื่อดูขยาย), ประวัติการแจ้งซ่อมล่าสุด และถ้ามีคนยืมอุปกรณ์นี้อยู่จะแสดงชื่อผู้ยืมไว้ด้วย
4. เลือกทำได้ 2 อย่างจากหน้าเดียวกันได้เลยโดยยังไม่ต้อง login:
   - **แจ้งซ่อมครุภัณฑ์นี้** — กรอกรายละเอียดปัญหา (บังคับ), ความเร่งด่วน (ต่ำ/ปานกลาง/สูง/วิกฤต), สถานที่ (ถ้ามี),
     เบอร์โทรติดต่อกลับ และ**แนบรูปเครื่อง/อาการเสียจากกล้องมือถือหรือคลังรูปได้สูงสุด 3 ภาพ** (กดไอคอนรูปเพื่อเลือกไฟล์
     เพิ่ม, กด ✕ มุมรูปเพื่อลบรูปที่เลือกไว้ก่อนส่ง)
   - **ยืมอุปกรณ์นี้/คืนอุปกรณ์นี้** (ปุ่มจะสลับกันเองอัตโนมัติตามว่าอุปกรณ์ว่างอยู่หรือมีคนยืมอยู่แล้ว) — กรอกวัตถุประสงค์
     การยืม/กำหนดคืน/สภาพตอนยืม (ถ้ายืม) หรือสภาพตอนคืน (ถ้าคืน)
5. กด **"ส่งแจ้งซ่อม"**/**"ยืนยันยืมอุปกรณ์"**/**"ยืนยันคืนอุปกรณ์"** แล้วแต่กรณี — ถ้ายังไม่ได้ login ระบบจะถามชื่อผู้ใช้และ
   รหัสผ่านตรงจุดนี้เอง (ไม่ต้องออกจากหน้านี้ไปหน้า login แยก) กรอกแล้วกดยืนยันอีกครั้ง ระบบจะส่งรายการที่กรอกไว้ (รวมรูปที่
   แนบ) ให้ทันที
   — ระบบออกเลขที่ใบแจ้งซ่อมให้ทันที (เช่น `2026-000125`) หรือบันทึกยืม-คืนสำเร็จ **ไม่ต้องรอเจ้าหน้าที่ไอทีบันทึกให้**
   ทำได้เองทั้งหมด ระบบจะแจ้งเตือนทั้งตัวท่านเองและเจ้าหน้าที่ไอทีให้รับทราบอัตโนมัติทุกครั้ง
   - ถ้าอุปกรณ์นี้มีคนอื่นยืมอยู่ ระบบจะแสดงชื่อผู้ยืมไว้เฉย ๆ (ไม่มีปุ่มคืนให้ เพราะต้องให้ผู้ยืมจริงหรือเจ้าหน้าที่ไอทีเป็น
     ผู้บันทึกคืน)

## 8.4 การแจ้งซ่อมผ่านเมนูในระบบ (กรณีไม่มี QR Code)

1. เข้าเมนู **"งานแจ้งซ่อม"** ในแถบเมนูซ้าย
2. กดปุ่ม **"แจ้งซ่อมใหม่"**
3. กรอกรายละเอียดปัญหา ความเร่งด่วน สถานที่ และเบอร์โทรติดต่อกลับ
4. กด **"ส่งแจ้งซ่อม"** — แนบรูป/วิดีโอประกอบได้สูงสุด 5 ไฟล์ต่อครั้ง (ไฟล์ละไม่เกิน 5 MB)

## 8.5 การติดตามสถานะงานซ่อม

1. เข้าเมนู **"งานแจ้งซ่อม"** — ระบบจะแสดงเฉพาะใบแจ้งซ่อมที่ท่านเป็นผู้แจ้งเท่านั้น (ค้นหารายการของตนเองได้จากเลขที่/
   รายละเอียด/ชื่อผู้แจ้งในช่องค้นหาด้านบนตาราง)
2. กดที่เลขที่ใบแจ้งซ่อมเพื่อดูรายละเอียด จะเห็น:
   - แถบความคืบหน้า (Progress %) และสถานะปัจจุบัน
   - **Timeline** แสดงประวัติทุกขั้นตอนตามลำดับเวลา (ใครทำอะไร เมื่อไหร่ พร้อมรูป/วิดีโอที่แนบไว้ครบทุกไฟล์) —
     ข้อมูลนี้ไม่สามารถแก้ไขหรือลบได้ ถือเป็นบันทึกถาวร
3. สามารถเพิ่มความคิดเห็นเพิ่มเติมได้ในช่อง "เพิ่มความคิดเห็น" ท้ายหน้ารายละเอียด

หากอุปกรณ์ของท่านต้องส่งซ่อมภายนอก (เช่น ส่งเคลมศูนย์บริการ) สถานะจะแสดงเป็น **"ส่งซ่อมภายนอก"** — เมื่อร้าน/บริษัท
ซ่อมเสร็จและส่งเครื่องคืนแล้ว ระบบจะย้ายสถานะกลับเข้าสู่ขั้นตอนปกติ (ทดสอบระบบ) โดยอัตโนมัติให้ต่อจนปิดงาน

สำหรับเจ้าหน้าที่ไอที/ช่างเทคนิค ที่หน้า "งานแจ้งซ่อม" มีปุ่ม **"มุมมองบอร์ด"** สลับไปดูงานทั้งหมดแบบ Kanban
(คอลัมน์ = สถานะงาน) ลากการ์ดข้ามคอลัมน์เพื่อเปลี่ยนสถานะงานได้โดยตรง — ระบบจะอนุญาตเฉพาะการลากไปยังสถานะที่เป็นขั้นตอน
ถัดไปจริงตาม workflow เท่านั้น (ลากข้ามขั้นตอนจะถูกปฏิเสธพร้อมข้อความแจ้งเตือน) งานที่ปิดหรือยกเลิกแล้วไม่แสดงบนบอร์ด
ให้ดูจากมุมมองตารางแทน

ระหว่างซ่อม ถ้าต้องใช้อะไหล่จากคลัง สามารถกด **"เบิกอะไหล่"** จากเมนู "..." มุมบนขวาของหน้ารายละเอียดใบแจ้งซ่อมได้เลย
(ต้องมีสิทธิ์เบิกอะไหล่) เลือกอะไหล่+จำนวน ระบบจะตัดสต็อกและบันทึกไว้ในส่วน "อะไหล่ที่เบิกใช้" ของใบแจ้งซ่อมนั้นทันที

## 8.6 การยืม-คืนครุภัณฑ์

1. วิธีที่เร็วที่สุด: **สแกน QR Code ที่ติดบนอุปกรณ์แล้วยืม/คืนได้เองทันที** — ดู § 8.3 ด้านบน (ไม่ต้องรอเจ้าหน้าที่ไอที
   บันทึกให้อีกต่อไป ทุกคนที่ login เข้าระบบยืม-คืนอุปกรณ์ของตัวเองผ่านสแกน QR ได้)
2. เมนู **"ยืมครุภัณฑ์-อุปกรณ์"** ในแถบเมนูซ้าย (ถ้ามีสิทธิ์เข้าถึง — โดยทั่วไปสำหรับเจ้าหน้าที่ไอที/ผู้ดูแลระบบ) ใช้ดู/จัดการ
   รายการยืม-คืนของทุกคนในองค์กร บันทึกยืม/คืนแทนผู้อื่นได้ — ดู [Admin Manual § 9.4](09-admin-manual.md)
3. สถานะที่พบ: **กำลังยืม** (ยังไม่ครบกำหนด), **เกินกำหนดคืน** (แจ้งเตือนซ้ำทุกวันจนกว่าจะคืน), **คืนแล้ว**

## 8.7 การแจ้งเตือน

ระบบแจ้งเตือนผ่าน **หลายช่องทางพร้อมกัน** เมื่อสถานะงานซ่อม/รายการยืม-คืนของท่านมีการเปลี่ยนแปลง:

- **อีเมล** ที่ลงทะเบียนไว้ในระบบ
- **กระดิ่งแจ้งเตือนในแอป** (มุมขวาบน) — อัปเดตแบบ realtime ทันทีที่มีเหตุการณ์เกิดขึ้นโดยไม่ต้องรีเฟรชหน้า มีตัวเลขนับข้อความ
  ที่ยังไม่อ่าน กดที่รายการแจ้งเตือนเพื่อดูรายละเอียดและพาไปหน้าที่เกี่ยวข้องโดยตรง กด "อ่านทั้งหมด" เพื่อล้างตัวเลขทีเดียว
- **การแจ้งเตือนของเบราว์เซอร์/Windows** — ครั้งแรกที่เข้าสู่ระบบ เบราว์เซอร์จะถามสิทธิ์ "อนุญาตให้แจ้งเตือน" กด **อนุญาต**
  เพื่อรับป๊อปอัปแจ้งเตือนจาก Windows (มุมขวาล่างจอ/Action Center) แม้ไม่ได้เปิดแท็บระบบอยู่ตรงหน้า — จะแจ้งเฉพาะตอนที่ไม่ได้
  โฟกัสแท็บนี้อยู่เท่านั้น (ถ้ากำลังดูหน้าจออยู่แล้ว กระดิ่งในแอปจะอัปเดตให้เห็นทันทีอยู่แล้ว ไม่ป๊อปอัปซ้ำ) กดที่ป๊อปอัปเพื่อสลับ
  กลับมาที่แท็บระบบได้ทันที
- **Telegram / LINE ส่วนตัว** (ถ้าตั้งค่าไว้ — ดูหัวข้อ 8.8)

หากยืมครุภัณฑ์เกินกำหนดคืน ระบบจะแจ้งเตือนซ้ำทุกวัน (เวลา 08:00) จนกว่าจะมีการบันทึกคืนในระบบ

## 8.8 การตั้งค่าช่องทางแจ้งเตือนส่วนตัว (Telegram / LINE)

รับแจ้งเตือนตรงถึงตัวท่านเองผ่าน Telegram หรือ LINE คู่ขนานกับอีเมลและกลุ่มไอทีกลาง:

1. กดที่รูปโปรไฟล์/ชื่อของท่านมุมขวาบน → **"ช่องทางการแจ้งเตือนส่วนตัว"**
2. **Telegram**: ส่งข้อความหาบอท `@userinfobot` ใน Telegram เพื่อดู Chat ID ของท่าน แล้วนำมากรอก
3. **LINE**: ติดต่อเจ้าหน้าที่ไอทีเพื่อขอ LINE User ID ของท่าน แล้วนำมากรอก
4. กด **"บันทึกช่องทางการแจ้งเตือน"** — หากเคยตั้งค่าไว้แล้ว ระบบจะแจ้งให้ทราบก่อนบันทึกทับ

## 8.9 รูปโปรไฟล์

1. กดที่รูปโปรไฟล์/ชื่อของท่านมุมขวาบน → **"รูปโปรไฟล์"**
2. กด **"เปลี่ยนรูป"** เพื่ออัปโหลดรูปของตนเอง (JPEG/PNG/WEBP/GIF ไม่เกิน 2 MB) หรือกด **"ลบรูป"** เพื่อกลับไปใช้ภาพเริ่มต้น
3. หากยังไม่ได้อัปโหลดรูป เลือก **"เพศ"** (ชาย/หญิง) เพื่อให้ระบบแสดงภาพ avatar เริ่มต้นที่เหมาะสมแทนไอคอนกลาง ๆ

| รับเรื่องแล้ว | เจ้าหน้าที่ไอทีรับเรื่องแล้ว |
| วิเคราะห์ปัญหา | ช่างกำลังตรวจสอบสาเหตุ |
| รออะไหล่ | รอจัดหาอะไหล่ก่อนซ่อม |
| กำลังซ่อม | อยู่ระหว่างซ่อมแซม |
| ซ่อมเสร็จสิ้น | ซ่อมเสร็จแล้ว รอส่งคืน |
| คืนอุปกรณ์แล้ว | ส่งคืนครุภัณฑ์ให้ท่านแล้ว |
| ผู้แจ้งรับมอบ | รอท่านยืนยันว่าได้รับอุปกรณ์คืนแล้ว |
| ปิดงาน | จบกระบวนการ |
| ยกเลิก | ใบแจ้งซ่อมถูกยกเลิก (จะระบุเหตุผลไว้ใน Timeline) |

## 8.11 ติดตั้งเป็นแอปบนมือถือ (PWA)

ระบบติดตั้งเป็นแอปบนหน้าจอโฮมของมือถือได้ (ไม่ต้องผ่าน App Store/Play Store) เปิดเร็วขึ้นและมีไอคอนแอปของตัวเอง — ข้อมูล
ทุกอย่างยังต้องใช้อินเทอร์เน็ตตามปกติ (ไม่รองรับการใช้งานแบบ offline)

**Android (Chrome)**:
1. เปิด URL ของระบบใน Chrome
2. กดเมนู ⋮ มุมบนขวา → **"ติดตั้งแอป"** (หรือ "เพิ่มไปยังหน้าจอโฮม")
3. ยืนยัน — จะมีไอคอนแอประบบขึ้นบนหน้าจอโฮมเหมือนแอปทั่วไป

**iOS (Safari)**:
1. เปิด URL ของระบบใน Safari (ต้องเป็น Safari เท่านั้น เบราว์เซอร์อื่นบน iOS ทำไม่ได้)
2. กดปุ่มแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) ที่แถบด้านล่าง
3. เลื่อนหาเมนู **"เพิ่มไปยังหน้าจอโฮม"** (Add to Home Screen) แล้วกดยืนยัน
