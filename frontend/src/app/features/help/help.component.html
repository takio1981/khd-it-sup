คู่มือการใช้งานระบบ

ขั้นตอนการใช้งานฟีเจอร์หลักของระบบ เรียงตามลำดับงานจริง — คลิกแต่ละหัวข้อเพื่อดูรายละเอียด

เริ่มต้นใช้งานระบบ
  1. เข้าสู่ระบบด้วย Username และรหัสผ่านที่เจ้าหน้าที่ไอทีสร้างให้ (หน้าแรกของระบบ)
  2. หากเป็นการเข้าสู่ระบบครั้งแรก หรือรหัสผ่านถูกรีเซ็ต ระบบจะบังคับให้เปลี่ยนรหัสผ่านใหม่ก่อนใช้งานต่อ
  3. เมนูด้านซ้ายจะแสดงเฉพาะรายการที่ตรงกับสิทธิ์การใช้งานของบัญชีเท่านั้น (ดูหัวข้อ "บทบาทและสิทธิ์การใช้งาน" ด้านล่าง)
  4. มุมขวาบน: ปุ่มพระอาทิตย์/พระจันทร์สลับโหมดสว่าง-มืด, กระดิ่งแจ้งเตือน, และเมนูผู้ใช้งาน (เปลี่ยนรหัสผ่าน/ออกจากระบบ)
 แดชบอร์ดภาพรวม
  1. หน้าแรกหลังเข้าสู่ระบบ แบ่งเป็นแท็บตามหัวข้อ: งานแจ้งซ่อม / ครุภัณฑ์ / ผู้ใช้งาน / ตำแหน่งงาน / หน่วยงาน / แผนก / การแจ้งเตือน
  2. แต่ละแท็บแสดงการ์ดตัวเลขสรุปและกราฟที่เกี่ยวข้องกับเรื่องนั้นๆ โดยเฉพาะ (เช่น แท็บ "ผู้ใช้งาน" แสดงกราฟแจกแจงตามสิทธิ์และหน่วยงาน)
  3. จะเห็นเฉพาะแท็บที่ตรงกับสิทธิ์การใช้งานของบัญชีเท่านั้น เช่น บัญชีที่ไม่มีสิทธิ์จัดการผู้ใช้งานจะไม่เห็นแท็บ "ผู้ใช้งาน"
 แจ้งซ่อมครุภัณฑ์ (สำหรับผู้แจ้ง)
  1. ไปที่เมนู "งานแจ้งซ่อม" แล้วกดปุ่ม "แจ้งซ่อมใหม่" มุมขวาบน
  2. เลือกครุภัณฑ์ที่ต้องการแจ้งซ่อม (ถ้าทราบเลขครุภัณฑ์ หรือสแกน QR Code ที่ติดอยู่บนตัวเครื่อง) กรอกรายละเอียดอาการเสีย ระดับความเร่งด่วน สถานที่ และเบอร์ติดต่อ
  3. กด "บันทึก" ระบบจะออกเลขที่ใบแจ้งซ่อมให้อัตโนมัติ และแจ้งเตือนไปยังเจ้าหน้าที่ไอทีทันที
  4. ติดตามความคืบหน้าได้จากหน้ารายละเอียดใบแจ้งซ่อม (แถบสถานะและ Timeline ด้านขวา)
  5. สามารถแนบรูปภาพหรือวิดีโอเพิ่มเติมได้ตลอดเวลาที่งานยังไม่ปิด (ปุ่ม "แนบไฟล์" — รองรับเฉพาะรูปภาพ/วิดีโอ ขนาดไม่เกิน 5 MB ต่อไฟล์)
  6. พิมพ์เอกสารใบแจ้งซ่อมได้จากเมนู ⌄ มุมขวาบนของหน้ารายละเอียด → "พิมพ์ใบแจ้งซ่อม"
 รับเรื่องและดำเนินการซ่อม (เจ้าหน้าที่ไอที/ช่างเทคนิค)
  1. เจ้าหน้าที่ไอทีเปิดใบแจ้งซ่อมที่มีสถานะ "แจ้งซ่อมแล้ว" แล้วกดเมนู ⌄ → "รับเรื่อง"
  2. กดเมนู ⌄ → "มอบหมายช่าง" เพื่อเลือกช่างเทคนิคผู้รับผิดชอบ
  3. ช่างเทคนิคเปลี่ยนสถานะงานตามขั้นตอนจริงผ่านเมนู ⌄ (เช่น ตรวจสอบเบื้องต้น → วิเคราะห์ปัญหา → รออะไหล่/กำลังซ่อม → ทดสอบระบบ) — ระบบจะเสนอเฉพาะสถานะถัดไปที่เป็นไปได้เท่านั้น
  4. ทุกครั้งที่เปลี่ยนสถานะ ระบบจะบันทึกลง Timeline แบบถาวร (แก้ไขหรือลบย้อนหลังไม่ได้ เพื่อความโปร่งใส) และแจ้งเตือนผู้เกี่ยวข้องอัตโนมัติผ่านทุกช่องทางที่เปิดใช้งานไว้ (อีเมล/Telegram/LINE — ดูหัวข้อ "ตั้งค่าและตรวจสอบระบบแจ้งเตือน")
  5. เมื่อซ่อมเสร็จ เลือก "ทดสอบผ่าน" ระบบจะเปิดฟอร์ม "สรุปผลการซ่อม" ให้กรอกก่อนเปลี่ยนสถานะเป็น "ซ่อมเสร็จสิ้น" เสมอ (ดูหัวข้อถัดไป)
  6. ขั้นตอนสุดท้าย: ผู้แจ้งกด "ปิดงาน" หลังตรวจรับเครื่องคืนเรียบร้อย
 สรุปผลการซ่อม และพิมพ์ใบแจ้งซ่อม
  1. เมื่อเปลี่ยนสถานะเป็น "ซ่อมเสร็จสิ้น" ระบบจะบังคับกรอก สาเหตุที่พบ และ วิธีการดำเนินการซ่อม (บังคับ) พร้อมช่องเสริม อะไหล่ที่ใช้ และข้อเสนอแนะป้องกัน
  2. หากต้องแก้ไขสรุปผลภายหลัง (เช่น กรอกข้อมูลเพิ่มเติม) กดปุ่ม "แก้ไข" ที่การ์ด "สรุปผลการซ่อมจากช่าง" ในหน้ารายละเอียด — แก้ไขได้โดยไม่ต้องเปลี่ยนสถานะงานซ่อม
  3. พิมพ์เอกสารทางการได้จากเมนู ⌄ → "พิมพ์ใบแจ้งซ่อม" — เอกสารจะรวมข้อมูลผู้แจ้ง/ครุภัณฑ์/อาการ/รูปภาพประกอบ/สรุปผลการซ่อม (ถ้ามี) และช่องลงนามให้ครบในหน้าเดียว พร้อมพิมพ์ทันที
 จัดการครุภัณฑ์
  1. เมนู "ครุภัณฑ์" → ปุ่ม "เพิ่มครุภัณฑ์" เพื่อบันทึกครุภัณฑ์ใหม่ (เลขครุภัณฑ์ระบบออกให้อัตโนมัติ)
  2. แก้ไขข้อมูลหรือเปลี่ยนสถานะครุภัณฑ์ (ใช้งานปกติ/อยู่ระหว่างซ่อม/รออะไหล่/ปิดใช้งาน ฯลฯ) ได้ทั้งจากเมนู ⌄ ในตาราง หรือปุ่ม "แก้ไข" ในหน้ารายละเอียดครุภัณฑ์
  3. ในฟอร์มเพิ่ม/แก้ไขครุภัณฑ์ สามารถระบุที่ตั้งจริงของเครื่องได้ (อาคาร → ชั้น → ห้อง ตามลำดับ) — ถ้ายังไม่มีอาคาร/ชั้น/ห้องที่ต้องการ ให้ไปเพิ่มที่เมนู "จัดการสถานที่/หน่วยงาน" ก่อน (ดูหัวข้อถัดไป)
  4. สร้าง QR Code จากปุ่ม "สร้าง QR" แล้วกด "พิมพ์ QR" เพื่อดูตัวอย่างสติกเกอร์ก่อนพิมพ์จริง (มีชื่อหน่วยงาน เลขครุภัณฑ์ และลิงก์สแกนตรวจสอบ)
  5. เลือกครุภัณฑ์หลายรายการในตาราง (ติ๊กช่องซ้าย) แล้วกด "พิมพ์ QR ที่เลือก" เพื่อพิมพ์สติกเกอร์ครั้งละหลายชิ้น
  6. ปุ่ม "จัดการประเภทครุภัณฑ์" มุมขวาบนของหน้ารายการ ใช้เพิ่ม/แก้ไขประเภทครุภัณฑ์ใหม่ๆ ที่ยังไม่มีในระบบ (เช่น อุปกรณ์รุ่นใหม่ที่ไม่อยู่ใน 14 ประเภทเริ่มต้น)
  7. คลิกเลขครุภัณฑ์เพื่อดูรายละเอียดและประวัติการแจ้งซ่อมทั้งหมดของเครื่องนั้น
 ยืม-คืนครุภัณฑ์
  1. เมนู "ยืม-คืนครุภัณฑ์-อุปกรณ์" → ปุ่ม "ยืมอุปกรณ์" เลือกครุภัณฑ์ (ต้องยังไม่ถูกยืมอยู่ — 1 ชิ้นยืมได้ครั้งละ 1 รายการเท่านั้น) ผู้ยืม กำหนดคืน วัตถุประสงค์ และสภาพเครื่องตอนยืม
  2. ช่อง "สถานที่ใช้งาน" เลือกจาก dropdown อาคาร → ชั้น → ห้อง ที่มีอยู่ในระบบเพื่อความสะดวก หรือถ้านำไปใช้นอกสถานที่ที่ไม่มีในระบบ ให้เลือก "อื่นๆ (นอกสถานที่)" ในช่องอาคารแล้วพิมพ์ระบุสถานที่เองในช่องด้านล่าง (บังคับกรอกเมื่อเลือกอื่นๆ)
  3. พนักงานทั่วไปที่มีสิทธิ์ "ยืม-คืนด้วยตนเอง" สามารถสแกน QR Code บนตัวครุภัณฑ์เพื่อยืม/คืนได้เองโดยไม่ต้องรอเจ้าหน้าที่ไอที — ระบบจะถามให้เข้าสู่ระบบตอนกดปุ่ม "บันทึก" เท่านั้น
  4. คลิกแถวในตารางรายการเพื่อเปิดหน้ารายละเอียด — แสดงข้อมูลการยืม สถานที่ปลายทาง ผู้ถือครอง/สถานที่ปัจจุบัน (ถ้ายังไม่คืน) จำนวนครั้งที่ระบบแจ้งเตือนเกินกำหนดคืนไปแล้ว และไทม์ไลน์เหตุการณ์ทั้งหมดของรายการนั้น (ยืม/ส่งต่อ-ย้าย/แจ้งเตือน/คืน) แบบถาวรแก้ไขย้อนหลังไม่ได้
  5. ถ้าอุปกรณ์มีการส่งต่อ/ย้ายมือระหว่างที่ยืมอยู่ (เช่น คนยืมเดิมส่งต่อให้เพื่อนร่วมงาน หรือย้ายไปใช้อีกที่หนึ่ง) กดปุ่ม "ส่งต่อ/ย้าย" ในหน้ารายละเอียด — ทำได้ทั้งผู้ถือครองปัจจุบันเอง (แม้ไม่มีสิทธิ์ยืม-คืนในระบบเลยก็ตาม) และเจ้าหน้าที่ไอที/แอดมิน ระบุผู้รับมอบใหม่และ/หรือสถานที่ใหม่ (dropdown + "อื่นๆ" เหมือนตอนยืม) ได้อย่างน้อยหนึ่งอย่าง
  6. ถ้าเกินวันกำหนดคืน ระบบจะแสดงป้าย "เกินกำหนด" ให้ทันทีบนรายการ (คำนวณสดจากวันที่ ไม่ต้องมีใครกดเปลี่ยนสถานะ) และมีงานอัตโนมัติแจ้งเตือนผู้ยืมซ้ำทุกวันจนกว่าจะคืน — จำนวนครั้งที่แจ้งเตือนไปแล้วแสดงในหน้ารายการ/รายละเอียด/รายงาน และการ์ดสรุป "เกินกำหนด+แจ้งเตือนซ้ำ" บนแดชบอร์ด ใช้เป็นสัญญาณให้สังเกตว่าผู้ยืมน่าจะลืมคืนหรือไม่
  7. การยืม/คืน/เกินกำหนดคืน แจ้งเตือนไปยังผู้ยืมและเจ้าหน้าที่ไอทีทุกคนผ่านช่องทางที่เปิดใช้งานไว้ (อีเมล/Telegram/LINE/แจ้งเตือนในแอป) ตรวจสอบประวัติการส่งได้ที่หัวข้อ "ตั้งค่าและตรวจสอบระบบแจ้งเตือน" ด้านล่าง
 จัดการผู้ใช้งาน
  1. เมนู "ผู้ใช้งาน" แสดงตารางรายชื่อและกราฟแจกแจงตามสิทธิ์/หน่วยงาน (ตัวเลขสรุปภาพรวมย้ายไปอยู่ที่แท็บ "ผู้ใช้งาน" ในหน้าแดชบอร์ดแล้ว)
  2. กด "เพิ่มผู้ใช้" เพื่อสร้างบัญชีใหม่ — เลือกสิทธิ์การใช้งาน หน่วยงาน และตำแหน่งงานได้ในฟอร์มเดียวกัน ระบบจะบังคับให้ผู้ใช้เปลี่ยนรหัสผ่านเองในการเข้าสู่ระบบครั้งแรกเสมอ
  3. ปุ่ม "จัดการตำแหน่งงาน" มุมขวาบน ใช้เพิ่ม/แก้ไขตำแหน่งงานที่ยังไม่มีในระบบ
  4. แก้ไขข้อมูล/สิทธิ์/หน่วยงานผ่านเมนู ⌄ ท้ายแถวในตาราง
  5. "รีเซ็ตรหัสผ่าน" ระบบจะสุ่มรหัสผ่านชั่วคราวและส่งเข้าอีเมลของผู้ใช้คนนั้นให้เองโดยอัตโนมัติ (ไม่แสดงรหัสผ่านให้ผู้ดูแลระบบเห็น/คัดลอกอีกต่อไป เพื่อความปลอดภัย) และบังคับเปลี่ยนรหัสผ่านครั้งถัดไปที่เข้าสู่ระบบ
  6. "ลบ" ผู้ใช้เป็นการปิดใช้งานบัญชี (Soft Delete) ไม่ได้ลบประวัติการทำงานที่ผ่านมาของผู้ใช้นั้นออกจากระบบ
 จัดการสถานที่/หน่วยงาน

หน่วยงาน

  1. กด "เพิ่มหน่วยงาน" กรอกรหัส ชื่อหน่วยงาน (ไทย/อังกฤษ) และเลือกหน่วยงานแม่ (ถ้าเป็นหน่วยงานย่อย)
  2. กด "แก้ไข" ท้ายแถวเพื่อแก้ชื่อหรือย้ายสังกัดหน่วยงานแม่ — รหัสหน่วยงานแก้ไขไม่ได้หลังสร้างแล้ว
  3. "ลบ" เป็นการปิดใช้งาน จะทำไม่ได้หากหน่วยงานนั้นยังมีหน่วยงานย่อย ผู้ใช้งาน หรือแผนกสังกัดอยู่ (ต้องย้ายข้อมูลออกก่อน)

แผนก

  1. ปุ่ม "จัดการแผนก" มุมขวาบน เปิดหน้าจัดการแผนกแยกต่างหาก
  2. แต่ละแผนกต้องเลือกหน่วยงานที่สังกัดเสมอ (1 หน่วยงานมีได้หลายแผนก)

อาคาร/ชั้น/ห้อง

  1. ปุ่ม "จัดการอาคาร/ชั้น/ห้อง" มุมขวาบน เปิดหน้าจัดการแบบ 3 คอลัมน์ — เลือกอาคารทางซ้ายเพื่อดูชั้น แล้วเลือกชั้นเพื่อดูห้อง ตามลำดับ
  2. แต่ละห้องสามารถระบุหน่วยงานที่ใช้งานห้องนั้นได้ (ไม่บังคับ) เพื่อดูสรุปจำนวนห้องต่อหน่วยงานในแดชบอร์ด
  3. ลบอาคาร/ชั้น/ห้องไม่ได้ถ้ายังมีชั้น/ห้อง/ครุภัณฑ์ผูกอยู่ (ต้องย้ายข้อมูลออกก่อน)
 ตั้งค่าและตรวจสอบระบบแจ้งเตือน
  1. เมนู "ตั้งค่าแจ้งเตือน" มี 2 แท็บ: "ประวัติการแจ้งเตือน" และ "ตั้งค่า" — เข้าถึงได้เฉพาะผู้ดูแลระบบเท่านั้น (สิทธิ์ "จัดการตั้งค่าระบบ")
  2. แท็บ "ประวัติการแจ้งเตือน" แสดงการแจ้งเตือนที่ระบบเคยส่งทุกช่องทาง (อีเมล/Telegram/LINE) พร้อมสถานะ (ส่งสำเร็จ/ส่งไม่สำเร็จ) และเหตุผลกรณีส่งไม่สำเร็จ — ใช้ตรวจสอบเวลาผู้ใช้แจ้งว่า "ไม่ได้รับการแจ้งเตือน"
  3. แท็บ "ตั้งค่า" แต่ละช่องทาง (แจ้งเตือนในแอป/อีเมล/Telegram/LINE) จะรวมสวิตช์เปิด/ปิดและค่าตั้งค่าของช่องทางนั้นไว้การ์ดเดียวกัน พร้อมปุ่ม "ทดสอบ" ส่งข้อความทดสอบจริงได้ทันทีด้วยค่าที่บันทึกไว้แล้ว (ใช้ตรวจสอบว่าตั้งค่าถูกต้องหรือไม่โดยไม่ต้องรอเหตุการณ์จริงเกิดขึ้น)
  4. Telegram/LINE: ค่าที่บันทึกไว้แล้ว (Chat ID/Bot Token, Group ID/Access Token) จะแสดงเป็นข้อมูลอ่านอย่างเดียวก่อนเสมอ (ค่า token/secret จะซ่อนเป็น "ตั้งค่าไว้แล้ว" ไม่แสดงค่าจริง) กดปุ่มไอคอนดินสอที่มุมขวาของการ์ดเพื่อเข้าสู่โหมดแก้ไข
  5. Telegram: สร้างบอทผ่าน @BotFather รับ Bot Token มา เชิญบอทเข้ากลุ่ม/แชทที่ต้องการรับแจ้งเตือน แล้วนำ Chat ID มากรอกในหัวข้อ "ตั้งค่า Telegram Bot" — ระบบส่งเข้าแชท/กลุ่มเดียวที่ตั้งไว้ (ไม่ผูกบัญชีรายคน)
  6. LINE: สร้าง LINE Official Account พร้อม Messaging API Channel ที่ LINE Developers Console นำ Channel Access Token มากรอก และเชิญบอทเข้ากลุ่ม/แชทที่ต้องการ แล้วนำ Group ID หรือ User ID มากรอกในหัวข้อ "ตั้งค่า LINE Messaging API" — ระบบส่งแบบ push เข้ากลุ่ม/แชทเดียวที่ตั้งไว้เท่านั้น (ไม่ใช่ broadcast ถึงทุกคนที่แอดเพื่อน OA)
  7. หัวข้อ "แจ้งเตือนเมื่อเกิดเหตุการณ์" เลือกได้ว่างานแจ้งซ่อมเหตุการณ์ไหนบ้าง (มีใบแจ้งซ่อมใหม่ / มอบหมายงาน / สถานะเปลี่ยน / ซ่อมเสร็จ / ยกเลิกงาน) ที่ต้องการให้แจ้งเตือน — มีผลกับทุกช่องทางที่เปิดใช้งานพร้อมกัน
 สำรอง/กู้คืนข้อมูล
  1. เมนู "สำรอง/กู้คืนข้อมูล" เข้าถึงได้เฉพาะผู้ดูแลระบบสูงสุด (SUPER_ADMIN) เท่านั้นตามค่าเริ่มต้นของระบบ
  2. แท็บ "รายการ" → ขยายแถบ "สำรองข้อมูลตอนนี้" เลือกขอบเขต (ทั้งหมด หรือเฉพาะบางตารางที่จัดกลุ่มไว้ให้) แล้วกด "เริ่มสำรองข้อมูล" — ทำงานเบื้องหลัง ไม่ต้องรอหน้าจอค้าง
  3. ไฟล์สำรองข้อมูลที่สร้างสำเร็จแล้วสามารถดาวน์โหลดหรือลบได้จากเมนู ⌄ ท้ายแถวในตาราง
  4. แท็บ "ตั้งค่าอัตโนมัติ" เปิดใช้งานการสำรองข้อมูลอัตโนมัติทุกวันเวลา 03:00 น. พร้อมกำหนดขอบเขตและจำนวนวันที่เก็บไฟล์ไว้ก่อนลบทิ้งเอง (retention — ไม่กระทบไฟล์ที่กดสำรองเองหรือไฟล์สำรองนิรภัยก่อนกู้คืน)
  5. การกู้คืนข้อมูล (เมนู ⌄ → "กู้คืนจากไฟล์นี้") เป็นปฏิบัติการที่แทนที่ข้อมูลปัจจุบันได้จริง จึงมีการป้องกันหลายชั้น: ต้องยืนยันรหัสผ่านของตัวเองซ้ำและพิมพ์ชื่อไฟล์ยืนยันให้ตรงเป๊ะ ระบบจะสำรองข้อมูลนิรภัย (SAFETY) แบบเต็มให้อัตโนมัติก่อนเริ่มกู้คืนเสมอโดยไม่มีทางปิดขั้นตอนนี้ได้ และแจ้งเตือนผู้ดูแลระบบสูงสุดทุกคนทุกครั้งที่กู้คืนสำเร็จหรือล้มเหลว
  6. กู้คืนข้อมูลเลือกได้เฉพาะ "ไฟล์สำรองไหน" เท่านั้น — ไม่สามารถเลือกเฉพาะบางตารางจากไฟล์สำรองแบบเต็มตอนกู้คืนได้ ขอบเขตของการกู้คืนเป็นไปตามขอบเขตที่ไฟล์นั้นถูกสำรองไว้ตั้งแต่ต้น
 บทบาทและสิทธิ์การใช้งานในระบบ
ผู้ดูแลระบบสูงสุด — เข้าถึงและตั้งค่าได้ทุกส่วนของระบบ รวมถึงการตั้งค่าแจ้งเตือน
ผู้ดูแลระบบ — จัดการครุภัณฑ์ งานซ่อม ผู้ใช้งาน หน่วยงาน และพิมพ์เอกสารได้ทั้งหมด ยกเว้นการตั้งค่าระบบระดับสูง
เจ้าหน้าที่ไอที — รับเรื่อง มอบหมายงาน เปลี่ยนสถานะงานซ่อม พิมพ์เอกสาร และดูครุภัณฑ์ได้ (ไม่สามารถจัดการผู้ใช้งาน/หน่วยงาน)
ช่างเทคนิค — เปลี่ยนสถานะงานซ่อมที่ได้รับมอบหมาย แนบไฟล์ และบันทึกสรุปผลการซ่อมได้ (ไม่เห็นเมนูแดชบอร์ด/พิมพ์เอกสาร)
ผู้ใช้งานทั่วไป — แจ้งซ่อมและติดตามงานของตนเองเท่านั้น
