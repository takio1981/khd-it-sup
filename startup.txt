แนะนำลำดับการทดสอบ
ลำดับ	ทำอะไร	จุดที่ควรสังเกต
1	ดู แดชบอร์ด	การ์ดสรุป/กราฟ จะว่างเปล่าตอนแรกเพราะยังไม่มีข้อมูล
2	เมนู ครุภัณฑ์ → "เพิ่มครุภัณฑ์"	สร้างเครื่องคอมพิวเตอร์สัก 1 เครื่อง ดูว่าได้เลขครุภัณฑ์อัตโนมัติ (IT-000001)
3	ที่หน้ารายละเอียดครุภัณฑ์ กด "สร้าง QR" แล้ว "พิมพ์ QR"	จะได้รูป QR จริงดาวน์โหลดมา
4	เปิด หน้าต่างไม่ระบุตัวตน (Incognito) แล้ว scan/เปิดลิงก์ QR นั้น (หรือคัดลอก URL จาก response ตอนกด "สร้าง QR")	จะเห็นหน้าสาธารณะแสดงข้อมูลครุภัณฑ์โดยไม่ต้อง login
5	ใน incognito กด "เข้าสู่ระบบเพื่อแจ้งซ่อม" → login → กลับมาแจ้งซ่อม	ทดสอบ flow แจ้งซ่อมผ่าน QR แบบเต็ม
6	กลับมาแท็บ admin ปกติ → เมนู "งานแจ้งซ่อม" → เปิดใบที่เพิ่งสร้าง	ทดสอบ "รับเรื่อง" → "มอบหมายช่าง" → "เปลี่ยนสถานะ" ไล่ตาม workflow ดู Timeline ที่บันทึกทุกขั้นตอน
7	เมนู "ผู้ใช้งาน" → เพิ่มผู้ใช้ทดสอบ role ต่างๆ (Technician, IT Officer) แล้ว login ด้วยบัญชีนั้นดูว่าเมนู/สิทธิ์ต่างกันจริง	ทดสอบ RBAC
8	กดปุ่ม 🌙 มุมขวาบน	ทดสอบ Dark Mode
9	กลับไปแดชบอร์ด	ตอนนี้ควรมีข้อมูลกราฟ/การ์ดแล้วจากที่สร้างไว้
ถ้าอยากทดสอบ API ตรงๆ (ไม่ผ่านหน้าเว็บ)
Swagger UI: http://localhost/api-docs — ยิง request ทดลองได้ในหน้าเว็บเลย
Postman: import ไฟล์ postman/khd-it-sup.postman_collection.json เข้า Postman แล้วรัน "Auth → Login" ก่อน (token จะถูกบันทึกอัตโนมัติให้ request อื่นใช้ต่อ) — แต่ต้องแก้ตัวแปร baseUrl ในคอลเลกชันจาก http://localhost:3000/api/v1 เป็น http://localhost/api/v1 ก่อน เพราะตอนนี้ backend อยู่หลัง Nginx ไม่ได้ expose พอร์ต 3000 ออกมาตรงๆ
เมื่อทดสอบเสร็จ

docker compose down          # หยุดระบบ (ข้อมูลที่สร้างไว้ยังอยู่ครบ)
docker compose down -v       # หยุด + ลบข้อมูลทั้งหมด กลับไปเป็นฐานข้อมูลว่างเปล่า+s
